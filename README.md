# Lumé Salon Website

Static premium salon website built with React + Vite, based on the supplied Lumé UI mockup.

## Run

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Main sections
Navbar, Hero, Stats, About, Services, Why Choose Us, Before/After, Offers, Team, Gallery, Pricing, Testimonials, Instagram, Appointment CTA, Location and Footer.

All design images used by the site are stored locally in `public/images/`.
